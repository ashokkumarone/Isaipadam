# Isaipadam — Unified Video & Audio Streaming Concept

A working prototype exploring a single unified experience for video and audio streaming — one app that lets users move seamlessly between watching and listening to the same content, instead of switching between separate apps for music and video.

## Why I built this

Music streaming, OTT video, and creator content today live in separate, single-purpose apps. Users juggle multiple subscriptions and multiple interfaces to consume content that could reasonably live in one place. Isaipadam is a product concept and interactive prototype for what a unified consumption experience could look like — with a one-click Audio Mode that transforms video playback into a battery- and data-efficient music player, without leaving the app.

## Key Features

- **Video / Music / Podcast modes** — switch between content types from a single navigation bar
- **Audio Mode** — converts any video into an optimized, battery-efficient audio player interface
- **Playlists, Library, History, Downloads** — with separate quality settings for video and audio
- **Full Settings panel** — playback quality, audio equalizer, dark mode, restricted mode
- **Premium subscription flow** — including a working coupon-code flow
- **Persistent mini-player** — with play/pause/skip controls across the whole app

## Tech Stack

- React 19 + TypeScript
- Tailwind CSS
- Framer Motion (animations)
- Vite
